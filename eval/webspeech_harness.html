Web Speech API harness

The browser's own recogniser cannot be pointed at a file — it only hears a live microphone. So this page plays each recording out loud through the speakers and lets Chrome's recogniser listen to the room, which is a manual protocol and is labelled as one in eval/results.md. Ten utterances, covering all three groups.

Before you start: turn the speakers up to a normal talking volume, and do not talk over it. Chrome may cancel its own speaker output as echo — if every row comes back empty, that is what happened, and the honest move is to record it as a gap rather than fake the rows. Web Speech has no code-switching mode at all, so each clip is run in the language of its group, and the mixed clips are run in both ar-EG and en-US.
